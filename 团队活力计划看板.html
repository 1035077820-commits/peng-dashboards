🔥 团队活力计划

国际事业部 · 17人 · 2026年7月-12月 · 预算2K/季

🎯 为什么做这个？

痛点：开会让分享想法没人发言 → 有想法怕被否定 → 怕担责出错 → 缺乏激情和归属感

目标：敢开口 → 敢担当 → 有创意 → 有归属 → 展现出比现在更好的状态

8月吐槽墙+印象

🔥

辩论赛

7月 / 11月

目的

被迫表达立场，发现"说了也没事" → 降低所有人的开口门槛

对团队的帮助：
• 立场是随机抽的 = 安全保护伞
• 练习快速组织语言和逻辑说服
• 辩完发现：说错了真的没有后果
✅ 激发分享欲：强制输出观点，练表达肌肉
📝

匿名吐槽墙

8月

目的

给安全出口，让"不敢说"变成"被允许说" → 建立"说了真的会改"的信任

对团队的帮助：
• 匿名 = 零风险，先迈第一步
• 你当场回应+承诺改 = 信任建立
• 为后面敢当面说打基础
⚡ 过渡性：先敢匿名说 → 后面才敢当面说
🌟

队友印象

8月 / 11月

目的

让每个人被看见、被认可 → 归属感拉满 → 更愿意主动表现

对团队的帮助：
• 发现"原来同事这么看我" → 自信提升
• 打破部门小圈子，跨组互相认可
• 被认可后自然更愿意表达
✅ 被认可后更愿意表现自己
🎭

角色扮演

9月

目的

模拟实战场景，全员支招 → 笑点多自然破冰 → 积累团队话术库

对团队的帮助：
• 演着演着就放开了，创意自然冒出来
• 全员共同解决问题 → 集体智慧
• 好的应对话术记录下来，团队共享
✅✅ 天然有笑点，创意自然冒出来
🎁

盲盒感谢

9月

目的

跨圈表达认可 → 打破隔阂 → 团队情感连接升温

对团队的帮助：
• 练"具体表达"能力（不能说泛泛的谢谢）
• 金队和出海之间建立情感连接
• 暖场用，为其他活动铺垫氛围
⚡ 暖场基础：为后续活动打开氛围
💡

疯狂提案

10月 季度重活动

目的

规则禁止说"不行" → 越荒谬越鼓励 → 释放创意无压力 → 好点子真的会落地

对团队的帮助：
• "怕被否定"的恐惧彻底消除
• 好点子给预算落地 → "我的想法真的管用了"
• 一旦体验到被采纳，创意就停不下来
✅✅✅ 最直接激发创意的活动
