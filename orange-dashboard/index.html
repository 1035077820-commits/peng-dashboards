二、为什么人效下降？

① 新人没活过来

  • 上半年进进出出，没有一个新人留存并产出
  • 每招一个人 = 2-3个月工资白烧 + 老人带教精力浪费
  • 结果：人数+0.8，收入+0

② 没有人才梯队

  • 老人没精力/方法带新人
  • 新人独立产出周期3-6个月才能开单
  • 没有“老带新→新独立→老做大客户”的良性循环

三、为什么人力成本上升？

  • 新人工资未产出期：8~9万（招了人但没留住/没产出）
  • 核心问题：花了更多的钱，但没买到增长

四、7-12月解决方案

方向1 · 控人数提人效

  • 不增员，现有7人做1845.9万
  • 跟单补位招有经验的（梓杏+小杨替补），缩短空窗
  • 管理兼业务，管理者也背数

方向2 · 提升人均产出

  • 525万缺口拆到个人：玉珠+207万 / 冯冯+146万 / 正瑶+94万 / 阿乐+78万
  • 大客户攻坚：品创等落地拉升单产
  • AI工具提效：减少重复劳动，时间还给客户开发
